## 🔐 AUTENTICAÇÃO


## 🏥 REDE DE SAÚDE

### GET `/api/estabelecimentos/proximos`
Retorna UPAs e hospitais ativos dentro do raio, ordenados por proximidade.

**Query Parameters:**
- `lat` (float, obrigatório): Latitude do usuário
- `lng` (float, obrigatório): Longitude do usuário
- `raio` (float, opcional): Raio de busca em km (default: 20)

**Example Request:**
```
GET /api/estabelecimentos/proximos?lat=-30.0333&lng=-51.2298&raio=20
```

**Response (200):**
```json
[
  {
    "id": 1,
    "nome": "UPA Bom Jesus",
    "tipo": "UPA",
    "distancia_km": 3.1,
    "endereco": "Rua Bom Jesus, 410",
    "bairro": "Bom Jesus",
    "telefone": "(51) 3289-5450",
    "horario_funcionamento": "24 Horas",
    "latitude": -30.046901,
    "longitude": -51.161118,
    "ativo": true,
    "cep": "91420-030",
    "codigo_cnes": "7712392"
  }
]
```

Quando nenhum estabelecimento estiver dentro do raio, a API retorna `200` com `[]`.

### GET `/api/estabelecimentos/por-cep`
Alternativa quando a pessoa não autorizar a geolocalização do navegador. O backend consulta ViaCEP e converte o endereço em coordenadas com Nominatim.

**Query Parameters:**
- `cep` (string, obrigatório): CEP com ou sem hífen
- `raio` (float, opcional): Raio de busca em km (default: 20)

**Response:** Mesmo formato de `/api/estabelecimentos/proximos`.

**Response (422):** CEP inválido ou não encontrado.

**Response (502):** Serviço externo de CEP/geocodificação indisponível.

## 📋 QUESTIONÁRIO

### GET `/api/questionario/perguntas`
Retorna as 9 perguntas e opções atuais. Textos e pesos são placeholders em revisão.

### POST `/api/questionario/resultado`
Recebe uma resposta para cada uma das 9 perguntas, calcula a pontuação e salva o resultado associado ao usuário.

**Request:**
```json
{
  "usuario_id": 42,
  "respostas": {
    "1": "b",
    "2": "c",
    "3": "a",
    "4": "d",
    "5": "a",
    "6": "b",
    "7": "c",
    "8": "b",
    "9": "a"
  }
}
```

**Response (200):**
```json
{
  "jornada_recomendada": "sono",
  "pontuacao": {
    "cardiaca": 6,
    "sono": 7,
    "respiratoria": 6
  },
  "empate": false,
  "mensagem": "Com base nas suas respostas, a Jornada do Sono é a mais indicada para você. Um bom descanso transforma tudo! 💚"
}
```

**Response (422) - Respostas incompletas, pergunta inexistente ou opção inválida:**
```json
{
  "detail": "Respostas incompletas. Perguntas não respondidas: 2, 5."
}
```

## 📝 Notas Importantes

- Os IDs de usuário usados pelo contrato são inteiros.
- A autenticação JWT está sendo integrada; os routers de questionário e estabelecimentos deste backend ainda não validam bearer tokens.
- Coordenadas geográficas usam latitude/longitude (WGS84)
- Distâncias são calculadas usando Fórmula de Haversine
- Timestamp padrão: ISO 8601 (UTC)
- O raio padrão da busca de estabelecimentos é 20 km.
- Todas as 9 respostas do questionário são obrigatórias; o desempate prioriza cardíaca, respiratória e sono.
